# 来校チェック

学校行事の受付名簿をブラウザ内で読み込み、来校者を名字・受付番号から素早く照合して来校記録を残すWebアプリです。現在の正本は **目高祭受付版** で、従来の見学会用Excelや別形式Excelも汎用列マッピングで利用できます。

## 目高祭の受付分類

- ① 在校生保護者
  - 1年 / 2年 / 3年 / 全学年
  - 生徒名簿の既存フリガナを使用
- ② 中学生・保護者
  - 9/5 / 9/6
  - 主申込者の名字フリガナで候補を絞り、元の氏名欄で本人のフルネームを確認
- ③ 一般
  - 9/5 / 9/6
- 全分類
  - 混雑時に3分類をまとめて検索

目高祭では `目高祭受付名簿.xlsx` の `全受付` シートを自動認識します。個人情報を含む名簿Excelはこのリポジトリには置きません。

## 検索

- 名字：漢字 / ひらがな / カタカナ
- 受付番号：全文
- 受付番号：下5桁
  - `20220` と `２０２２０` を同一視
- 読みが複数ある名字は複数候補を検索キーに保持
- 中学生・保護者の家族名等は検索キーの中心にせず、候補表示後の本人確認に使用

## 本番受付

通常は3列を分類別に運用します。

- 受付A：① 在校生保護者
- 受付B：② 中学生・保護者
- 受付C：③ 一般

混雑時や列が崩れた場合は、各端末の画面上で分類をその場で切り替えられます。「全分類」を選ぶと、その日の全来校者を同じ検索欄から探せます。

## 受付記録

- 1タップ受付
- 受付時刻
- 受付済み表示
- 受付取消
- 名簿外来校者登録
- 日付別受付（9/5と9/6は別記録）
- 来校記録CSV
- 名簿外CSV
- バックアップJSON

## 自動保存・再開

受付記録と読み込んだ名簿は端末内のブラウザ保存領域へ自動保存します。画面を閉じても、同じ端末・同じブラウザなら「前回の受付を続ける」から再開できます。

## 複数端末同期

各PCに同じ名簿を読み込み、⚙設定から同じ同期コードを設定します。同一LANは不要です。各PCが学校Wi-Fi、別Wi-Fi、テザリング等でインターネットへ出られれば受付済み状態を共有します。

同期サーバーへ保存するのは次のみです。

- 名簿と同期コードから生成した匿名ID
- 受付 / 取消
- 受付時刻
- 受付端末名

氏名、フリガナ、学校名などの名簿内容は送信しません。

通信断中も各端末で受付を継続し、未同期分を端末内に保存します。通信復旧後に自動同期します。通信断中だけは他端末の最新受付が見えないため、二重受付に注意が必要です。

## 個人情報

実名名簿は GitHub / GitHub Pages / ZIP に含めません。受付PCでローカルに読み込みます。共有PCでは受付終了後、バックアップを確認してから「この端末から名簿＋受付データを完全削除」を使用できます。

## 2026年度第1回学校説明会の受付（2026-10-24）

名簿の1行目に次の8項目が並ぶExcel/CSVを自動認識します。元データの見出しにはフリガナの説明語がつながっており（例：`生徒氏名セイトシメイ`）、その場合も認識するよう対応済みです。

`受付番号 / 生徒氏名 / フリガナ / 学年 / 中学校名 / 希望オプション / 保護者名 / 参加人数`

- Excel原本は304件、全8列・2行目以降がデータ。受付番号、氏名、フリガナで検索し、保護者氏名、参加人数、希望オプションを表示します。
- A.学校見学ツアー / B.個別相談会 / C.特推説明会 / D.希望無しを基本とし、名称のわずかな揺れは元の文言を保持します。希望オプション未記入2件は「要確認」。
- 人数の`2`、`2人`、`２⼈`、`2名（受験生と保護者）`、`子供1人、同伴者1人`などを**画面上のみ「2名」**に統一します（1名・3名も同様）。元データを変更しません。
- 参加人数が空欄の22件、`はい。`、`かしこまりました`など、実人数を確定できない値は「要確認」と表示します。確認が必要なケースを自動的に2名扱いにはしません。
- **2026-10-23にアップロードされた新旧ExcelをXML上で直接再照合した結果、両方とも計算式0件、304行×8列の値はすべて一致し、どの列にも「15」というセル値はありません。** 旧版に「15」があるという以前のAIの分析は誤りです。
- 当落情報の列がないため、**勝手に全員当選とは判定しません**。名簿内の候補は「名簿登録あり」、集計は「名簿内受付済／未受付／名簿外」と表示します。抽選結果が必要なら別途確定情報で照合します。

### 当日の手順

1. 受付端末で今回のExcel名簿を読み込むと、8列を自動認識します。名簿に実名が含まれるためGitHubには置きません。
2. 複数受付端末を使う場合は今回専用の同期コードを設定し、各端末に同じ名簿を読み込みます。
3. 受付番号または氏名で来校者を検索し、本人と保護者氏名・申込希望オプション・人数を照合します。
4. 「要確認」が出た場合は該当情報を尋ねます。人数の未記入を2名と決めつけません。
5. 受付確認後「この方で受付」を押し、終了後は記録のバックアップと共有端末のデータ削除を行います。

この改修では希望内容の変更履歴やオプション別人数集計は実装しません。リアル名簿は端末内のみで、氏名・希望内容は既存匿名同期サーバーに送りません。

目高祭モード、一般のExcel列割り当て、オフライン受付は維持します。新しい公開作業や本番マージは実施していません。

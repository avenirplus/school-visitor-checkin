# 来校チェック

学校行事の受付名簿をブラウザ内で読み込み、来校者を名字・受付番号から素早く照合して来校記録を残すWebアプリです。現在の正本は **目高祭受付版** で、従来の見学会用Excelや別形式Excelも汎用列マッピングで利用できます。

## 目高祭の受付分類

- ① 在校生保護者
  - 1年 / 2年 / 3年 / 全学年
  - 生徒名簿の既存フリガナを使用
- ② 中学生・保護者
  - 9/5 / 9/6
  - 主申込者の名字フリガナで候補を絞り、元の氏名欄で本人のフルネームを確認
- ③ 一般
  - 9/5 / 9/6
- 全分類
  - 混雑時に3分類をまとめて検索

目高祭では `目高祭受付名簿.xlsx` の `全受付` シートを自動認識します。個人情報を含む名簿Excelはこのリポジトリには置きません。

## 検索

- 名字：漢字 / ひらがな / カタカナ
- 受付番号：全文
- 受付番号：下5桁
  - `20220` と `２０２２０` を同一視
- 読みが複数ある名字は複数候補を検索キーに保持
- 中学生・保護者の家族名等は検索キーの中心にせず、候補表示後の本人確認に使用

## 本番受付

通常は3列を分類別に運用します。

- 受付A：① 在校生保護者
- 受付B：② 中学生・保護者
- 受付C：③ 一般

混雑時や列が崩れた場合は、各端末の画面上で分類をその場で切り替えられます。「全分類」を選ぶと、その日の全来校者を同じ検索欄から探せます。

## 受付記録

- 1タップ受付
- 受付時刻
- 受付済み表示
- 受付取消
- 名簿外来校者登録
- 日付別受付（9/5と9/6は別記録）
- 来校記録CSV
- 名簿外CSV
- バックアップJSON

## 自動保存・再開

受付記録と読み込んだ名簿は端末内のブラウザ保存領域へ自動保存します。画面を閉じても、同じ端末・同じブラウザなら「前回の受付を続ける」から再開できます。

## 複数端末同期

各PCに同じ名簿を読み込み、⚙設定から同じ同期コードを設定します。同一LANは不要です。各PCが学校Wi-Fi、別Wi-Fi、テザリング等でインターネットへ出られれば受付済み状態を共有します。

同期サーバーへ保存するのは次のみです。

- 名簿と同期コードから生成した匿名ID
- 受付 / 取消
- 受付時刻
- 受付端末名

氏名、フリガナ、学校名などの名簿内容は送信しません。

通信断中も各端末で受付を継続し、未同期分を端末内に保存します。通信復旧後に自動同期します。通信断中だけは他端末の最新受付が見えないため、二重受付に注意が必要です。

## 個人情報

実名名簿は GitHub / GitHub Pages / ZIP に含めません。受付PCでローカルに読み込みます。共有PCでは受付終了後、バックアップを確認してから「この端末から名簿＋受付データを完全削除」を使用できます。

## 2026年度第1回学校説明会の受付（2026-10-24）

このイベントの受付用名簿は、下記のヘッダーが1行目にあるExcel/CSVを **自動認識** します。

`受付番号 / 生徒氏名 / フリガナ / 学年 / 中学校名 / 希望オプション / 保護者名 / 参加人数`

- 1行目はヘッダー、2行目以降を来校者データとして取り込みます。
- 受付番号、氏名、フリガナで検索します。保護者氏名、参加人数、申込時の希望オプションも表示します。
- 申込時の希望オプションはA.学校見学ツアー / B.個別相談会 / C.特推説明会 / D.希望無しの4種類です。
- 元の表記に「A.生徒による校舎案内」「B.個別相談」があってもそのまま表示します。
- 通常のA〜D以外の希望値は、明確に「要確認」を出します。
- 人数欄の「15」「はい。」「かしこまりました」なども要確認にします。原本の値を勝手に2名へ修正しません。
- 学年に「15」が入っている場合も要確認を添えます。
- この名簿には当落列がないため、**当選・落選を推測しません**。名簿内は「名簿登録あり」、集計は「名簿内受付済／未受付／名簿外」に切り替えます。

### 当日の手順

1. 各受付端末で同一の学校説明会名簿を読み込む（自動認識）。
2. 複数端末を使う場合は今回専用の同期コードを設定する。
3. 来校者に受付番号を示してもらい、番号または氏名で検索する。
4. 生徒氏名と保護者氏名・人数・申込時の希望オプションを照合する。
5. 内容が合えば「この方で受付」を押す。「要確認」が出た場合は担当者に確認してから進める。
6. 受付記録をエクスポートし、バックアップを確認した後に共有端末の名簿を削除する。

この改修では受け付けた希望の変更記録やオプションごとの追加集計は行いません。実名簿はGitHubには置きません。同期サーバーに希望内容や氏名は送りません。

元の目高祭モードおよび汎用Excel列割り当ては維持します。上記以外の形式は従来どおり手動で列設定できます。

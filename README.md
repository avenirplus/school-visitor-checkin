# 来校チェック

学校行事の受付名簿をブラウザ内で読み込み、来校者を名字・受付番号から素早く照合して来校記録を残すWebアプリです。現在の正本は **目高祭受付版** で、従来の見学会用Excelや別形式Excelも汎用列マッピングで利用できます。

## 目高祭の受付分類

- ① 在校生保護者
  - 1年 / 2年 / 3年 / 全学年
  - 生徒名簿の既存フリガナを使用
- ② 中学生・保護者
  - 9/5 / 9/6
  - 主申込者の名字フリガナで候補を絞り、元の氏名欄で本人のフルネームを確認
- ③ 一般
  - 9/5 / 9/6
- 全分類
  - 混雑時に3分類をまとめて検索

目高祭では `目高祭受付名簿.xlsx` の `全受付` シートを自動認識します。個人情報を含む名簿Excelはこのリポジトリには置きません。

## 検索

- 名字：漢字 / ひらがな / カタカナ
- 受付番号：全文
- 受付番号：下5桁
  - `20220` と `２０２２０` を同一視
- 読みが複数ある名字は複数候補を検索キーに保持
- 中学生・保護者の家族名等は検索キーの中心にせず、候補表示後の本人確認に使用

## 本番受付

通常は3列を分類別に運用します。

- 受付A：① 在校生保護者
- 受付B：② 中学生・保護者
- 受付C：③ 一般

混雑時や列が崩れた場合は、各端末の画面上で分類をその場で切り替えられます。「全分類」を選ぶと、その日の全来校者を同じ検索欄から探せます。

## 受付記録

- 1タップ受付
- 受付時刻
- 受付済み表示
- 受付取消
- 名簿外来校者登録
- 日付別受付（9/5と9/6は別記録）
- 来校記録CSV
- 名簿外CSV
- バックアップJSON

## 自動保存・再開

受付記録と読み込んだ名簿は端末内のブラウザ保存領域へ自動保存します。画面を閉じても、同じ端末・同じブラウザなら「前回の受付を続ける」から再開できます。

## 複数端末同期

各PCに同じ名簿を読み込み、⚙設定から同じ同期コードを設定します。同一LANは不要です。各PCが学校Wi-Fi、別Wi-Fi、テザリング等でインターネットへ出られれば受付済み状態を共有します。

同期サーバーへ保存するのは次のみです。

- 名簿と同期コードから生成した匿名ID
- 受付 / 取消
- 受付時刻
- 受付端末名

氏名、フリガナ、学校名などの名簿内容は送信しません。

通信断中も各端末で受付を継続し、未同期分を端末内に保存します。通信復旧後に自動同期します。通信断中だけは他端末の最新受付が見えないため、二重受付に注意が必要です。

## 個人情報

実名名簿は GitHub / GitHub Pages / ZIP に含めません。受付PCでローカルに読み込みます。共有PCでは受付終了後、バックアップを確認してから「この端末から名簿＋受付データを完全削除」を使用できます。

## 学校説明会：申込時の希望オプション表示（2026-10）

既存の「補助情報列」を、学校説明会では申込時の希望オプション表示に再利用できます。専用バックエンドは増やさず、実名簿をGitHubに保存しません。

### 受付用データの準備
1. LoGoフォーム等から申込者名簿をExcel/CSVで取得し、当選・出席可能な申込者の受付番号、氏名、フリガナ、人数、申込時の希望オプションを残す。
2. 「希望オプション」等の1列を設け、申込原文を残す。別列で出力される場合は、既存列を消さず、受付表示用に1列へ結合したコピーを作る。
3. アプリの「名簿の列設定」で「希望オプション／補助情報列」にこの列を指定する（列の自動判定はしない）。
4. 受付番号または氏名で検索し、候補カード内の「申込時の希望オプション」を見ながら来校者に口頭確認する。
5. 氏名と希望内容を照合してから「この方で受付」を押す。希望変更の処理はこの機能では行わない。

対象となる代表的な語句：校舎案内、校内案内、施設見学、個別相談、特別推薦、硬式野球、バスケット、希望なし。これらを含む値は強調表示し、それ以外の補助情報は従来どおり表示します。選択状態をアプリ側で推測・補完せず、名簿に記録された文字列をそのまま表示します。

**注意**
- 空欄は「希望なし」と同義ではありません。元の申込データと照合してください。
- 実際のLoGoフォーム出力列名と値は、実名簿の例を学校内で確認して列を指定してください。架空の当選者・希望情報で本番運用しないでください。
- 「当落列」と「当選とみなす値」も実際の抽選データに合わせて確認してください。指定しないと既存アプリは当選表示になりません。
- 同一受付番号の重複、取消、オフライン、複数端末同期など既存の受付動作は変更していません。イベントごとに新しい同期コードを使い、各端末で同じ名簿を読み込んでください。
- この表示拡張のみでは受付記録CSVへ希望オプションは追加されません。必要なら別途要件確認してください。
